# Perfume Darbar (Next.js 15, App Router, Tailwind v4)
npm install && npm run dev    # http://localhost:3000
Deploy: push to GitHub and import in Vercel (no env vars needed).

Real photos: put product photos in public/products/ named by slug (see public/products/README.txt).
Catalog and collections: lib/products.ts. Blog, FAQ, policies: lib/content.ts.
Cart and wishlist use localStorage. Checkout, login, account and orders use demo data.
